# VisaBridge Android - isolated free build
This branch contains only an offline sample Android build. It does NOT overwrite DareDash on main.
The native Java/Android source and the static visa-assistance demonstration are in VisaBridge-Android-CI-source.zip.
Open GitHub Actions > VisaBridge Android (free APK + AAB), then download the VisaBridge-APK-and-AAB artifact for a debug-installable APK and unsigned release AAB. No paid Lovable/Replit plan is required to build with GitHub free runner minutes, subject to account limits.
The APK is a demo only. No real passport intake, login, payment processing, government application submission or visa approval services are enabled. Do not enter actual customer personal information.
Google Play requires an upload-key-signed release AAB, API 36, valid policy disclosures, account verification and app review. Do not upload an unsigned AAB.
Full source and instructions are also available in VisaBridge-Android-Source.zip in the ChatGPT conversation.
